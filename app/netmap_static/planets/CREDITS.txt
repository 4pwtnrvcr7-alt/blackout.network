Solar explorer planet surfaces and landing-site data (pt1837u / pt1841u, Nov 24 2026).
All imagery is U.S. government public domain (NASA, JPL, USGS, Goddard, ASU,
JHUAPL) except where a generated stand-in is noted. Each file was resized and
recompressed; metadata was stripped. No non-commercial sources.

moon.jpg
  Source: NASA SVS CGI Moon Kit, "Lroc color poles" map (LRO LROC WAC color
  mosaic with LOLA fill at the poles). Map centered on 0 longitude.
  https://svs.gsfc.nasa.gov/4720/
  Author: NASA / Goddard / Arizona State University (LROC), LOLA team
  License: Public domain (U.S. government work)
  Obtained via the Wikimedia Commons copy of the same NASA map (File:CGI Moon
  Kit - Lroc color poles.tif), resized to 3840x1920 JPEG. Slightly
  desaturated so the surface reads as a neutral gray, closer to LRO true
  appearance (the source map has a faint warm tint).

mars.jpg
  Source: Viking Orbiter Colorized Mars Digital Image Model (MDIM) 2.1,
  global simple-cylindrical mosaic. Approximate natural color
  (butterscotch / rust with polar ice).
  https://astrogeology.usgs.gov/search/map/mars_viking_colorized_global_mosaic_232m
  Author: NASA Ames / JPL / USGS Astrogeology Science Center
  License: Public domain (U.S. government work)
  Obtained as the Commons copy File:Mars Viking MDIM21 ClrMosaic 1km.jpg
  (21,339x10,670), resized to 3840x1920 JPEG. A light saturation and
  contrast grade only; the v1 globe looked pale mainly because the
  material was tone-mapped with ACES. Planet maps now use sRGB encoding
  and are not ACES-tonemapped.

venus.jpg
  No public-domain cylindrical map of Venus visible-light cloud tops
  (true color) was available. The v1 file was the Magellan radar surface
  mosaic, which is not how Venus looks from space. This file is a
  generated, very-low-contrast pale-cream stand-in, color-matched to the
  usual visible-light appearance of Venus (soft sulfur cream; cloud
  markings in visible wavelengths are faint). It is not a radar map and
  is not a projected Galileo or Mariner mosaic.

saturn.jpg
  No official public-domain 2k cylindrical color map of Saturn's atmosphere
  was available. This is a generated latitude-band texture in natural-color
  golds sampled from Cassini portraits (NASA / JPL / SSI). It is a
  stand-in, not a projected Cassini mosaic. The north-pole hexagon is a
  separate overlay (see saturn_hex.webp).

uranus.jpg
  A generated smooth texture in Voyager 2 true-color tones sampled from the
  left (true-color) half of PIA00032, "Uranus in True and False Color."
  NASA / JPL. Public domain. Color-matched again to that pale cyan. Not a
  cylindrical projection of the Voyager frames; Uranus showed very few
  visible features at Voyager's resolution.

neptune.jpg
  A generated smooth texture in Voyager 2 true-color tones, color-matched
  to Voyager natural-color portraits (deep blue, not electric). NASA / JPL.
  Public domain. The Great Dark Spot was a transient storm in 1989 and is
  not drawn here as if it were still present.

sites.json
  Landing-site coordinates and mission facts from NASA NSSDC spacecraft
  records (public U.S. government information). Links are in each record.
  Great Red Spot position is measured on PIA07782 (Cassini, Dec 2000).

auroras (Earth, Jupiter, Saturn)
  Illustrative additive ovals, not photographs and not a live
  space-weather feed. Drawn as thin translucent rings (soft gradient,
  low opacity) at typical auroral colatitudes: Earth near 67 degrees
  magnetic latitude, with magnetic poles near 80.7 N, 72.7 W and
  74.3 S, 125.6 E; Jupiter a tighter oval with the dipole tilted
  about 10 degrees; Saturn a faint oval aligned with the spin axis.
  They are drawn as thin translucent rings so they read at the limb rather than as a solid cap. Colors
  are stylized toward common visible / published appearances (green
  for Earth, magenta for Jupiter, pale blue-violet for Saturn).
